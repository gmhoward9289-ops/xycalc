xycalc — how much X does it take to run Y?

Infrastructure sizing from a corpus where every number cites a source.

Two guarantees, enforced by a build that fails when they break: every figure cites a source, and every figure names the versions it applies to. Plus one made by admission — every model says how much reality it has been checked against.

This page is not showing you a number.

Its arithmetic disagrees with the corpus it was built from, on at least one case where the two were supposed to agree exactly. Until that is fixed, every figure it could render is suspect, so it renders none. Use the terminal — pip install xycalc && xycalc sizing — which computes from the corpus directly.
